# app-privacy-policy

Privacy policy hub for apps published by JamilXT. Hosted at https://jamilxt.github.io/app-privacy-policy/

## Adding a new app

1. Create a folder named after the app (lowercase, hyphens), e.g. `my-new-app/`
2. Add an `index.html` inside it with the app's privacy policy
3. Add a card for it in the root `index.html` navigation list
4. Commit and push - GitHub Pages rebuilds automatically
